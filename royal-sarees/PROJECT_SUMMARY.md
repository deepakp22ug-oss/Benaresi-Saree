## 🚀 How to Get Started

### 1. **View the Website Locally**
```bash
cd "c:\Users\DEEPAK PANDEY\Desktop\VS Code saree\royal-sarees"
python -m http.server 8000
# Then open http://localhost:8000 in your browser
```

### 2. **Customize for Your Brand**
- Update product names and descriptions
- Add your own images
- Change contact information
- Update social media links
- Modify colors if desired (in style.css)

### 3. **Add Your Products**
- Edit `data/products.js`
- Add product images to `images/` folder
- Update product details and prices
- Add more collections

### 4. **Deploy to the Web**
- **Option 1**: Netlify (drag and drop)
- **Option 2**: GitHub Pages (free hosting)
- **Option 3**: Your own server (FTP/SSH)
- **Option 4**: Web hosting provider
