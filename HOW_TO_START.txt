🔍 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════

❌ Chrome won't open or shows "Can't reach this page"
   → Make sure both servers are running (see STEP 1 & 2 above)
   → Wait 10-15 seconds for servers to fully start
   → Refresh page (Ctrl + R)

❌ Backend showing errors
   → Make sure you're in: royal-sarees-backend folder
   → Run: npm install (to reinstall dependencies)
   → Then: npm start

❌ Frontend showing blank page
   → Open Chrome DevTools (F12)
   → Check Console tab for errors
   → Try: Clear cache (Ctrl + Shift + Delete)
   → Refresh (Ctrl + R)

❌ "Port 5174 is already in use"
   → Kill process on port 5174: netstat -ano | findstr :5174
   → Or use: taskkill /PID [PID] /F
   → Then restart: npm run dev

❌ Products not showing
   → Check backend is running
   → Open: http://localhost:5000/api/health
   → Should see: {"status":"OK"}
